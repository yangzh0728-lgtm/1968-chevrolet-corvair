# Legacy Garage 26 — Website Proposal

## Why the website exists

1. **Keep the project record:** preserve restoration progress, photographs, discoveries, and decisions in one lasting archive.
2. **Save people’s stories:** organize interviews and videos so they remain easy to find beyond a social media feed.
3. **Share what we learn:** connect Corvair engineering, history, and useful resources with the restoration project.

Instagram provides short-form updates and reach. The website provides context, organized collections, and long-term access. Instagram remains linked from the footer and Videos page; it does not need a separate website page.
